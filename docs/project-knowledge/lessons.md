## User Preferences
- **Spatial-canvas editing must FEEL in-place, not "open another file" (2026-06-20):** When you `Enter` a NetherCanvas card to edit, the user must perceive editing as happening *inside that card on the canvas* — the canvas stays, the card is the focus, and you return to exactly the file+cursor the canvas was opened from. The single-buffer editor *technically* switches the active buffer to the card's file under the hood (to reuse the full vim/insert/undo/LSP engine = "main editor thu nhỏ"), but that switch must be invisible (deep scrim, lifted card, statusbar shows the FOCAL file not the card file) and reversed on exit (`canvas_restore_origin_buffer`). Never leave the user stranded in the card's file. Corollary the user stated: `+`/`-` adjust context of the **focused card only** (per-card, in place — never re-stack/disturb other cards); and canvas-mode keys (`hjkl`/`+`/`-`/pan/focus) must support press-and-hold key-repeat like the palette `j/k`.
- **Recent Projects normal-only actions need visible palette mode (2026-06-18):** If a Recent Projects action only works after `Esc`/palette Normal mode (e.g. `x` remove), the UI must show the same `-- NORMAL --` / `-- INSERT --` status as file/symbol pickers. Otherwise it is confusing because users cannot tell why `x` filters in Insert but removes in Normal.
- **Tab-bar colors + font size unified (2026-06-16):** All dock tab bars (left/right/bottom) AND the main-editor must share one look, matched to the main editor as the reference. (1) Color: base on the (darker) `theme.editor.bg`, NOT the lighter `panel_bg`; selected/active tab only subtly lighter (blend ~5% toward `fg`, ≈ rgb(24,27,34)) — "đừng làm trắng quá". (2) Font size: tab titles must render at the main-editor title size `theme.editor.font_size` — the strips compute `font = editor.font_size` but previously never called `set_metrics`, so they rendered at each text-system's default (sidebar/panel sizes) and looked bigger/inconsistent. Fix: `set_metrics(editor font)` around the label loop with save/restore (the text system is shared with the list/body). Set in `build_left_tab_strip` (sidebar.rs), `build_right_tab_strip` (test_runner.rs), `update_terminal_tab_bar` (terminal.rs).
- **Editor breadcrumb belongs in a main-editor header (2026-06-16):** Breadcrumb must render as a header bar at the top of the main editor pane (like Explorer/Outline/TestRunner panel headers), NOT in the topbar. It should always show the file name + file icon and append symbol segments when available — independent of LSP symbol presence.
- **Yank flash UX tuning (2026-06-16):** User prefers yank flash at 100ms with max opacity around 0.25, and expects all keyboard yank variants (`y`, `yy`, `ye`, `y{motion}`, visual `y`) to produce the same flash feedback.
- **User runs the editor via `cargo run --release` from the repo (2026-06-12):** so CWD = repo and the active UI profile is the repo's `config/ui/default.toml` (+ `~/.config/netherize/ui.toml` field overrides). The /Applications bundle and ~/.local/bin copies are secondary.

- **[2026-06-21] Clippy denies `x || true` as a logic bug:** The project has `clippy::overly_complex_bool_expr` denied, so do not force redraw/handled semantics with `changed || true` or `result.changed || true`. Preserve required side effects with `let _ = changed;` / `let _ = self.refresh...();` and return `true` directly.
- **[2026-06-21] NetherCanvas scope-aware cards (progressive refine):** Card snapshots spawn instantly with the ±N window, then progressively re-source to the enclosing-definition scope. Flow: `attach_canvas_relations` (async_results/lsp.rs) snapshots pre-spawn `BlockId`s, then per new card: if `origin.path == cached_document_symbols_path` (active file) → resolve **synchronously** via `enclosing_definition` (canvas_scope.rs, picks deepest Function/Method/Constant/Constructor from flat `documentSymbol` list) + `build_canvas_relation_snapshot_range` (clamps 60 lines + "+N more") + `canvas_apply_card_scope` (replace snapshot + regrow top-left fixed, Focal guard); else emit `CanvasCardScopeRequest { card_id, uri }` → worker `handle_lsp_document_symbols` (best-effort: empty symbols on any error, NO toast) → `CanvasCardScopeResult` → handler drops stale results via `canvas_card_scope_target` (None if card closed/focal). `CanvasState.next_id` is private — identify new cards by diffing a pre-spawn id snapshot, not by peeking next_id. The focal anchor is never drawn as a card (renderer `continue`s on `BlockRelation::Focal`), so scope-resolving it is a no-op — `canvas_apply_card_scope` guards Focal and the useful path is for RELATION cards.
- **[2026-06-21] Canvas card badge = card-edit modes only:** `card_mode_label(EditorMode) -> Option<&'static str>` (render/renderer/helpers.rs) returns `Some("NORMAL"/"INSERT"/"VISUAL")` only for Normal/Insert/Visual/VisualBlock; app-global modes (PaletteFocus/TerminalFocus/TerminalNormal/MultiCursor/MultiInsert/Resize) return `None`.
