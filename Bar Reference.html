A
Mode pill — phần tử đầu tiên, cao bằng toàn bộ status bar (height: 100%). Màu nền thay đổi theo mode:
NORMAL → --accent   INSERT → cyan   VISUAL → lilac   DEBUG → --warn   FIND → blue
Text luôn là màu tối để tương phản cao. Font 700 · 10px · letter-spacing 0.8px.
B
Arrow ❯ + file path — ngăn cách mode pill và tên file.
Arrow --fg-ghost. File path --fg-dim.
Nếu file đã được sửa nhưng chưa save: thêm ● sau tên (.modified::after), màu --accent.
C
Spacer — flex: 1 đẩy tất cả items phía sau sang bên phải. Không có nội dung. Đây là điểm phân chia trái ↔ phải của status bar.
D
Diagnostics — kết quả từ rust-analyzer / LSP:
✓ 0 errors màu --good  ·  ✗ 3 errors màu --err  ·  1 warning màu --warn
E
Language · Encoding · EOL — Rust · utf-8 · LF. Tất cả màu --fg-faint. Chỉ hiện khi cần, ẩn đi trong một số mode.
