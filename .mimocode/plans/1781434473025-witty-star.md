# Refactor Plan: Tách file quá lớn cho AI context

## Mục tiêu
Chỉ tách những file **quá lớn khiến AI khó đọc/nắm context**. File nào nhỏ, manageable thì giữ nguyên — dù có thể mixed responsibilities.

## Ngưỡng
- **> 2,000 dòng** → BẮT BUỘC tách
- **1,500 - 2,000 dòng** → Xem xét tách nếu nhiều responsibilities
- **< 1,500 dòng** → Giữ nguyên

## Nguyên tắc
- Không đổi logic, không đổi public API, không đổi behavior
- Tách theo responsibility/domain boundary tự nhiên
- Mỗi file mới nên 300-600 dòng
- Test files tách tương ứng
